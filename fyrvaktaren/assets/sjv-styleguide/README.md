# sjv-styleguide

Fyrvaktaren byggdes ursprungligen med [Jordbruksverkets styleguide](https://styleguide.jordbruksverket.se/) med dess komponenter, eftersom npm-paketet med styleguiden tillgänglig publik, därför bifogas relevanta CSS-filer här.

Filerna i denna mapp kommer från Jordbruksverkets sjv-styleguide v20.3.1.
